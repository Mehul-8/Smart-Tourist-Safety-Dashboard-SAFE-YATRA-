## Overview
The **Smart Tourist Safety Dashboard** serves as a centralized Command & Control (C2) console for tourism boards, park authorities, municipal police, and emergency response teams. Built with lightweight, zero-dependency vanilla web technologies and powered by Firebase Firestore and Authentication, it provides sub-second live telemetry updates, risk distribution analysis, interactive geofence zone creation, and one-click incident triage.
